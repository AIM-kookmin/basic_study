# 4주차 리더 진행 가이드

PPT의 발표자 노트와 동일한 설명을 검색 가능한 형태로 제공합니다. 정확도·손실의 고정 정답은 없으며 실습 결과를 직접 비교합니다.

## 01. Attention ② 작은 Transformer 만들기
**오프닝 · 00–02분 · 이번 주에 만들 결과물 확인**

3주차 attention과 문자 코퍼스를 독립적으로 다시 정의해 이전 실행 상태 없이 시작할 수 있다. 기본 실습은 짧은 문맥과 작은 모델을 사용한다. 대형 모델 학습이나 챗봇 품질을 목표로 하지 않는다.

## 02. 90분 수업 지도
**운영 · 02–05분 · 실습 노트북 열기**

시작 전에 실습의 환경 셀과 데이터 다운로드를 실행해 둔다. 핵심 구간의 종료 시간을 지키고 심화 질문은 부록으로 연결한다. 실습은 실행만 하는 시간이 아니라 예측, 관찰, 설명까지 포함한다.

## 03. 단일 헤드에서 multi-head로
**개념 · 05–20분**

헤드마다 문법적 역할이 자동으로 하나씩 배정되는 것은 아니다. 서로 다른 혼합을 학습할 수 있는 구조적 여지를 준다고 설명한다.

## 04. 블록의 두 하위 연산
**개념 · 05–20분**

FFN은 위치별 같은 가중치를 사용하며 직접 다른 위치를 참조하지 않는다. CNN의 1×1 Conv와 채널 변환 관점에서 연결할 수 있다.

## 05. LayerNorm과 BatchNorm
**개념 · 05–20분**

LayerNorm에도 학습 가능한 scale과 bias가 있다. 정규화 차원을 지정하는 normalized_shape가 중요하다. B,T까지 함께 정규화하지 않도록 한다.

## 06. pre-norm으로 쌓기
**개념 · 05–20분**

원래 Transformer 논문의 post-norm과 수업의 pre-norm이 다르다는 점을 명시한다. 교육용 구현을 원문 완전 복제라고 소개하지 않는다.

## 07. 학습과 생성의 계산 차이
**개념 · 05–20분**

오늘 생성 코드는 전체 문맥을 반복 계산해 단순하지만 비효율적이다. KV cache는 부록에서 개념만 다룬다.

## 08. decoder-only 모델의 범위
**개념 · 05–20분**

구조를 배운 것과 대규모 데이터에서 능력이 생기는 것을 구분한다. 작은 모델의 철자 생성 결과를 과장하지 않는다.

## 09. 좋은 평가 단위
**개념 · 05–20분**

랜덤 배치 몇 개만 뽑으면 평가가 흔들린다. 노트북은 평가 시 고정된 연속 window를 사용하고 같은 표본에 대해 비교한다.

## 10. 헤드 shape 변환
**수식 · 20–35분**

d_model이 heads로 나누어 떨어져야 한다. head 수를 늘린다고 d_model 고정에서 projection 파라미터가 단순히 head 수 배로 늘지 않는다.

## 11. 헤드 결합하기
**수식 · 20–35분**

transpose 후 메모리 배치가 비연속일 수 있어 view 전에 contiguous가 필요하다. reshape는 필요한 경우 복사할 수 있다. 버그가 나면 shape뿐 아니라 축 의미를 읽는다.

## 12. FFN의 폭과 파라미터
**수식 · 20–35분**

D×4D와 4D×D를 더해 8D²다. Q,K,V,O 투영은 약 4D²이므로 작은 블록에서도 FFN을 무시할 수 없다.

## 13. LayerNorm 계산
**수식 · 20–35분**

노트북의 nn.LayerNorm(D)는 마지막 D축에 적용한다. 정규화로 모든 값이 같은 것이 아니라 평균과 스케일을 조정하는 것이다.

## 14. top-k sampling
**수식 · 20–35분**

ties 처리 때문에 임계값 방식은 k개보다 많이 남길 수 있다. 실습은 topk 인덱스를 scatter해 정확히 k개를 남긴다. k는 1부터 vocabulary 크기까지 제한한다.

## 15. perplexity 해석
**수식 · 20–35분**

배치별 perplexity의 평균과 전체 CE의 exp는 다르다. loss를 먼저 표본 수로 집계한 뒤 exp한다. 같은 vocabulary의 uniform baseline도 참고할 수 있다.

## 16. 모듈을 네 부분으로 나누기
**설계 · 35–50분**

한 클래스에 모든 연산을 넣기보다 기능별로 나누면 shape와 causal 테스트가 쉽다. notebook은 외부 모듈 import 없이 모든 정의를 포함한다.

## 17. dropout이 평가를 흔들지 않게
**설계 · 35–50분**

no_grad만 사용하면 dropout은 계속 작동한다. 직접 구현은 nn.Dropout을 사용하며 SDPA의 dropout_p 설정과 규칙이 다르다.

## 18. 학습 안정성 점검
**설계 · 35–50분**

clip을 backward 전에 호출하면 현재 gradient가 없다. clipping은 데이터 누출이나 잘못된 loss를 고쳐 주지 않는다. max_norm=1.0은 수업 기본값이지 보편적 최적값이 아니다.

## 19. 실험 예산을 명시하기
**설계 · 35–50분**

모델이 보는 window는 겹칠 수 있어 처리 토큰 수가 고유 데이터 양과 같지 않다. GPU를 바꾸면 같은 시간 예산의 업데이트 수가 달라진다.

## 20. checkpoint에 넣을 것
**설계 · 35–50분**

state_dict만으로 다른 모델 구조를 자동 복원할 수 없다. 외부 출처 checkpoint를 무심코 실행하지 말고 본인이 만든 파일을 읽는다. 실습은 로컬 생성 파일만 사용한다.

## 21. LAB 1 · multi-head 구현 검사
**실습 · 50–75분 · practice.ipynb와 함께 진행**

mask는 모든 head와 batch에 브로드캐스트된다. 미래 변경은 중간 위치 이후만 바꾸고 그 이전 출력들을 비교한다. padding 없는 고정 window를 사용한다.

## 22. LAB 2 · 학습과 평가
**실습 · 50–75분 · practice.ipynb와 함께 진행**

시간이 부족하면 steps를 줄이되 평가 셀을 생략하지 않는다. 기본 학습으로 유창한 문장이 나오지 않을 수 있다. 검증 보고서의 실제 출력과 함께 설명한다.

## 23. LAB 3 · 생성 제어
**실습 · 50–75분 · practice.ipynb와 함께 진행**

각 조건을 여러 번 봐야 안정적으로 평가할 수 있다. 과도하게 높은 온도는 다양성뿐 아니라 오류도 늘릴 수 있다. 저장 파일은 실행 위치의 outputs 폴더에 생성된다.

## 24. 어떤 샘플링이 좋은가
**분석 · 75–85분**

샘플링 변화는 가중치를 다시 학습하는 것이 아니다. 생성 알고리즘과 모델 학습을 구분해서 보고한다.

## 25. 헤드 수 실험 해석
**분석 · 75–85분**

더 많은 헤드가 더 많은 독립 지식을 저장한다는 설명은 피한다. 다른 분할 방식이 최적화와 표현에 영향을 주는 것을 실험한다.

## 26. 학습 데이터와 생성 결과
**분석 · 75–85분**

데이터의 문법 자체가 단순하므로 평가 난도가 낮다. 모델 능력을 논하려면 더 다양한 실제 held-out 데이터와 적합한 지표가 필요하다.

## 27. 출구 퀴즈
**회고 · 85–90분**

정답: 16, 직접 섞지 않음, model.eval(). no_grad는 메모리 절약과 gradient 비활성화를 위해 함께 사용한다.

## 28. 다음: 확률 분포에서 이미지 생성
**회고 · 85–90분**

autoregressive 모델과 VAE는 생성 분해 방식이 다르다. VAE가 언어 모델을 대체하는 후속 단계라기보다 다른 생성 모델 계열이라고 설명한다.

## 29. 부록 · sinusoidal position
**부록 · 수업 외 심화**

수업 구현은 learned positional embedding을 쓴다. 원 논문의 위치 표현과 차이를 비교한다. 모양을 그려 주파수가 다른 축들을 관찰한다.

## 30. 부록 · KV cache
**부록 · 수업 외 심화**

오늘 sliding window와 learned position을 그대로 캐시화하면 위치 재설정 문제가 생긴다. 단순히 과거 K,V를 붙이는 것만으로 정확한 구현이 되지 않을 수 있다.

## 31. 부록 · weight tying
**부록 · 수업 외 심화**

수업 핵심은 독립 가중치를 사용한다. tying을 추가할 때 optimizer가 중복 업데이트하지 않는지 파라미터 집계를 확인한다.

## 32. 부록 · top-p sampling
**부록 · 수업 외 심화**

threshold를 넘기는 첫 토큰을 포함할지의 구현을 주의한다. 자율 과제의 도전 구현으로 제안하며 핵심 실습은 top-k까지만 한다.

## 33. 부록 · SDPA 사용 시 주의
**부록 · 수업 외 심화**

공식 문서를 확인한 뒤 사용한다. bool mask는 True=허용이다. 수치 허용 오차는 dtype과 device에 맞춰 설정한다.

## 34. 부록 · 긴 문맥과 학습 예산
**부록 · 수업 외 심화**

정확히 같은 모든 조건을 동시에 고정할 수 없는 경우가 있다. 무엇을 고정하고 무엇이 바뀌었는지 표에 명시하는 것이 중요하다.

## 35. 부록 · 작은 프로젝트 제안
**부록 · 수업 외 심화**

좋은 실험에는 실패 사례와 개선되지 않은 조건도 포함된다. 리더 해설의 참고 구현으로 단위 검사를 확인하고 결과 해석은 직접 작성한다.

## 36. 시각 보충 · 미래를 가리는 삼각형
**시각 보충 · 수업 외 복습 · 해당 개념 설명 시 함께 활용 가능**

0-based index에서 세 번째 행을 가리킨다. 대각선을 차단하지 않는다. 첫 행도 자기 자신을 볼 수 있어 all-masked softmax NaN을 피한다.

## 37. 시각 보충 · head 분할과 결합
**시각 보충 · 수업 외 복습 · 해당 개념 설명 시 함께 활용 가능**

4개 head로 나누어도 최종 D는 64다. 실제 Q,K,V는 각각 [B,4,T,16]으로 계산한다. 이 도식은 head별 결과 결합을 보여 준다.

## 38. 시각 보충 · next-token shift
**시각 보충 · 수업 외 복습 · 해당 개념 설명 시 함께 활용 가능**

입력 길이 T에 대해 원본 토큰 T+1개가 필요하다. 다음 토큰 정답은 입력의 바로 다음 열이므로 causal mask가 없으면 정답을 볼 수 있다.

## 39. 시각 보충 · temperature와 확률
**시각 보충 · 수업 외 복습 · 해당 개념 설명 시 함께 활용 가능**

실제 학습 모델의 결과가 아닌 설명용 logits의 정확한 softmax 계산이다. 온도를 높이면 분포가 완만해진다. τ=0은 허용하지 않는다.
