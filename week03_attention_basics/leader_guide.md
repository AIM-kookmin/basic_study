# 3주차 리더 진행 가이드

PPT의 발표자 노트와 동일한 설명을 검색 가능한 형태로 제공합니다. 정확도·손실의 고정 정답은 없으며 실습 결과를 직접 비교합니다.

## 01. Attention ① 관계를 계산하는 방법
**오프닝 · 00–02분 · 이번 주에 만들 결과물 확인**

행렬 곱, softmax, cross entropy를 복습한다. 외부 텍스트 다운로드 없이 교육용으로 직접 만든 문장 코퍼스를 사용한다. 결과는 언어 모델 원리 관찰용이며 자연어 능력 벤치마크가 아니다.

## 02. 90분 수업 지도
**운영 · 02–05분 · 실습 노트북 열기**

시작 전에 실습의 환경 셀과 데이터 다운로드를 실행해 둔다. 핵심 구간의 종료 시간을 지키고 심화 질문은 부록으로 연결한다. 실습은 실행만 하는 시간이 아니라 예측, 관찰, 설명까지 포함한다.

## 03. 언어 모델의 과제
**개념 · 05–20분**

토큰은 단어와 같지 않다. 오늘은 구현이 단순한 문자 단위를 사용한다. 실제 대형 언어 모델의 subword 토큰화와는 다르다.

## 04. 문자를 정수로 바꾸기
**개념 · 05–20분**

정수 ID의 크기는 의미적 순서가 아니다. ID 7이 ID 3보다 어떤 의미로 크다는 뜻이 아니다. embedding은 학습되는 lookup table이다.

## 05. 고정 문맥의 한계
**개념 · 05–20분**

문맥 창 밖 정보는 오늘 모델에서 접근할 수 없다. 어텐션이 모든 기억을 무한히 보관하는 구조가 아님을 짚는다.

## 06. Q·K·V의 역할
**개념 · 05–20분**

도서관 검색 비유는 직관일 뿐 각 차원이 실제 검색어에 대응하는 것은 아니다. 세 투영은 서로 다른 학습 파라미터다. self-attention에서는 같은 X에서 세 가지를 만든다.

## 07. self와 cross attention
**개념 · 05–20분**

원래 Transformer 논문은 encoder-decoder 구조다. 이 수업의 소형 문자 모델은 decoder-only 교육용 모델이며 논문 전체를 그대로 재현하지 않는다.

## 08. 미래를 보지 않는 규칙
**개념 · 05–20분**

mask 없이 한 칸 밀린 정답을 학습하면 뒤 위치의 정답 정보가 들어와 손실이 부당하게 낮아진다. 입력에 현재 문자는 있고 목표는 그 다음 문자이므로 대각선은 허용한다.

## 09. 위치 정보가 필요한 이유
**개념 · 05–20분**

causal mask도 순서 구조를 제공하지만 위치 embedding은 위치를 명시적으로 표현한다. 순서를 전혀 모른다는 단정 대신 명시적 위치 표현의 목적을 설명한다.

## 10. 전체 식을 세 단계로 읽기
**수식 · 20–35분**

softmax는 key 축인 마지막 차원에 적용한다. query마다 별도의 확률 분포가 나온다. 값의 차원 d_v는 일반적으로 d_k와 같을 필요가 없지만 오늘은 같게 둔다.

## 11. shape 추적표
**수식 · 20–35분**

transpose를 배치 축에 적용하는 실수를 경계한다. B는 독립된 시퀀스 묶음이다. 다른 배치의 문장끼리 attention하지 않는다.

## 12. 손계산 · 두 key와 한 query
**수식 · 20–35분**

내적, 나눗셈, 지수와 정규화, value 가중합을 순서대로 적는다. output은 key 벡터의 평균이 아니라 value 벡터의 가중합이라는 점을 다시 확인한다.

## 13. 왜 sqrt(d_k)로 나눌까
**수식 · 20–35분**

이는 초기 분포에 대한 직관이지 모든 학습 시점의 정확한 분산 보장이 아니다. 큰 logits에서는 softmax가 포화해 gradient가 작아질 수 있다.

## 14. causal mask 손으로 채우기
**수식 · 20–35분**

softmax 전에 mask를 더하거나 masked_fill한다. 행 전체를 −∞로 만들면 NaN이 될 수 있다. 오늘의 대각선 허용 mask는 각 행에 최소 한 개 허용 위치가 있다.

## 15. 언어 모델 손실
**수식 · 20–35분**

perplexity는 같은 tokenizer, 데이터, 평가 조건에서 비교한다. 문자 모델과 subword 모델의 perplexity를 그대로 비교하면 의미가 다르다. 자연로그 CE를 사용하므로 exp를 취한다.

## 16. 한 헤드부터 직접 구현
**설계 · 35–50분**

이 모델은 residual과 FFN을 갖춘 완전한 Transformer block이 아니다. 4주차에서 그 요소를 추가한다. 간단한 모델로 attention 핵심을 분리해 배운다.

## 17. softmax 축을 검증하기
**설계 · 35–50분**

softmax(dim=1)처럼 query 축을 정규화해도 shape는 맞아 오류가 숨을 수 있다. shape 검사만으로 충분하지 않아 의미적 불변량을 함께 확인한다.

## 18. 코퍼스를 먼저 분할하기
**설계 · 35–50분**

교육용 코퍼스는 동일 문법의 조합 문장이다. exact duplicate 문장은 split 간 중복되지 않지만 문법과 단어는 공유하므로 일반 자연어 일반화 증거가 아니다. UNK 비율을 확인한다.

## 19. 입력과 target 확인
**설계 · 35–50분**

train과 val 토큰을 이어 붙여 window를 만들면 경계를 넘어 데이터가 섞인다. 노트북 함수는 주어진 split만 사용한다. 생성 prompt도 vocabulary 범위 안으로 인코딩한다.

## 20. 샘플링은 선택 규칙이다
**설계 · 35–50분**

temperature가 낮아지면 더 집중된다. 생성에는 eval과 no_grad를 사용하고 문맥을 마지막 block_size만 남긴다. 같은 prompt라도 seed와 설정에 따라 결과가 달라진다.

## 21. LAB 1 · attention 연산 구현
**실습 · 50–75분 · practice.ipynb와 함께 진행**

heatmap의 행은 query, 열은 key다. 숫자를 읽어 첫 행이 자기 자신에 1을 주는지 확인한다. 이 손계산 Q,K,V는 학습된 값이 아닌 설명용 값이다.

## 22. LAB 2 · 문자 언어 모델 학습
**실습 · 50–75분 · practice.ipynb와 함께 진행**

두 모델은 구조와 파라미터 수가 달라 엄밀한 attention 단독 효과 실험은 아니다. 유의미한 방향을 관찰하는 기준 비교다. 최종 선택은 val을 사용한다.

## 23. LAB 3 · 생성과 누출 검사
**실습 · 50–75분 · practice.ipynb와 함께 진행**

미래 변경에 앞부분 logits가 변하면 mask나 attention 계산 축을 점검한다. eval 모드로 dropout 등을 끈 뒤 비교해야 한다. 어텐션 가중치를 문법 이해의 직접 증거로 해석하지 않는다.

## 24. 좋은 문자열과 좋은 모델
**분석 · 75–85분**

작은 합성 코퍼스는 생성 모델의 흐름을 보여 주기 위한 장치다. 작은 perplexity가 실제 글쓰기 능력을 의미하지 않는다. 선택한 좋은 샘플만 발표하지 않는다.

## 25. mask를 빼면 왜 손실이 낮을까
**분석 · 75–85분**

양방향 attention 자체가 잘못된 것은 아니다. causal 다음 토큰 학습이라는 목적과 맞지 않는 것이 문제다. masked language modeling과 구분한다.

## 26. attention 그림의 한계
**분석 · 75–85분**

특정 key의 value를 제거하거나 토큰을 바꾸는 실험도 가능하지만 그 역시 분포 변화를 만든다. 해석의 한계를 명시하는 습관을 배운다.

## 27. 출구 퀴즈
**회고 · 85–90분**

정답: 행=query, 열=key; softmax 전; 일반적으로 다르다. 후에 0으로만 지우면 행 합이 1이 아니며 재정규화 등 별도 처리가 필요하다.

## 28. 다음: 여러 관점과 깊이
**회고 · 85–90분**

자율 과제에서는 SDPA 공식 API와 직접 구현을 비교한다. API마다 boolean mask의 의미가 다를 수 있음을 다음 부록과 연결한다.

## 29. 부록 · 안정적인 softmax
**부록 · 수업 외 심화**

softmax 함수의 이동 불변성을 손으로 유도한다. temperature로 나누는 스케일 변환과 최댓값을 빼는 이동은 다른 연산이다.

## 30. 부록 · padding mask
**부록 · 수업 외 심화**

오늘 고정 길이 window에는 padding이 필요 없다. attention mask와 loss mask는 서로 대체되지 않는다. 모두 masked인 query 행의 NaN도 고려한다.

## 31. 부록 · API의 boolean mask
**부록 · 수업 외 심화**

수업 구현은 변수명을 blocked로 두어 True=차단을 명시한다. SDPA와 비교할 때는 ~blocked를 전달한다. 규칙을 외우기보다 작은 행렬로 검증한다.

## 32. 부록 · 문맥 길이와 비용
**부록 · 수업 외 심화**

효율적 구현은 전체 행렬 저장을 줄일 수 있으나 수업의 명시적 구현은 실제 T² 행렬을 만든다. 계산 복잡도와 메모리 구현을 구분한다.

## 33. 부록 · tokenizer의 선택
**부록 · 수업 외 심화**

오늘 영문 합성 코퍼스를 쓰는 이유는 원리를 가볍게 실행하기 위해서다. 한국어로 바꿀 때는 자모와 완성형 문자, 띄어쓰기 정책도 고려한다.

## 34. 부록 · 온도 손계산
**부록 · 수업 외 심화**

temperature=0을 나눗셈에 넣지 않는다. greedy는 별도 argmax 분기로 구현한다. ties가 있으면 극한의 설명에도 주의한다.

## 35. 부록 · baseline의 가치
**부록 · 수업 외 심화**

짧은 코퍼스에서 bigram도 일부 철자 패턴을 학습한다. 더 복잡한 모델이 제한된 시간 안에 항상 이기는 것은 아니다.

## 36. 시각 보충 · 미래를 가리는 삼각형
**시각 보충 · 수업 외 복습 · 해당 개념 설명 시 함께 활용 가능**

0-based index에서 세 번째 행을 가리킨다. 대각선을 차단하지 않는다. 첫 행도 자기 자신을 볼 수 있어 all-masked softmax NaN을 피한다.

## 37. 시각 보충 · head 분할과 결합
**시각 보충 · 수업 외 복습 · 해당 개념 설명 시 함께 활용 가능**

4개 head로 나누어도 최종 D는 64다. 실제 Q,K,V는 각각 [B,4,T,16]으로 계산한다. 이 도식은 head별 결과 결합을 보여 준다.

## 38. 시각 보충 · next-token shift
**시각 보충 · 수업 외 복습 · 해당 개념 설명 시 함께 활용 가능**

입력 길이 T에 대해 원본 토큰 T+1개가 필요하다. 다음 토큰 정답은 입력의 바로 다음 열이므로 causal mask가 없으면 정답을 볼 수 있다.

## 39. 시각 보충 · temperature와 확률
**시각 보충 · 수업 외 복습 · 해당 개념 설명 시 함께 활용 가능**

실제 학습 모델의 결과가 아닌 설명용 logits의 정확한 softmax 계산이다. 온도를 높이면 분포가 완만해진다. τ=0은 허용하지 않는다.
