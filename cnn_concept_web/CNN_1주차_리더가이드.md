# CNN 1주차 개념 수업 · 리더 가이드

새 PDF와 웹페이지의 페이지 번호를 따릅니다. 기존 코드 중심 PPT의 페이지 번호와 다릅니다. 90분은 관찰·개념 설명·종이 활동·토론으로 구성합니다. 노트북 실행은 별도 선택 활동입니다.

## 운영 원칙
- 먼저 그림을 보고 예상한 뒤 설명을 읽습니다.
- 인간 시각과 CNN의 대응은 한계를 포함해 말합니다.
- 설명용 숫자·가상 사례를 실제 모델 측정값으로 소개하지 않습니다.
- 활동 해설 페이지는 개인·짝 계산 후 공개합니다.

## 01. 숫자 한 장에서, 분류의 원리까지.
표지에서는 신경망 구조부터 설명하지 않는다. 같은 사진에서 무엇이 있는지 묻는 것과 어디 있는지 묻는 것이 다른 과제라는 질문으로 시작한다.


핵심: 이름을 붙이는 일에서, 이름을 만드는 계산까지.

## 02. 오늘의 길은 네 단계다.
p1–5 15분, p6–8 15분, p9–18 30분, p19–27 25분, p28 5분. MNIST 학습은 미리 실행된 실제 결과를 읽는다. 수업 중 전체 코딩을 추가하지 않는다.


핵심: 과제 15 + 사람 15 + 기초 용어 30 + MNIST 25 + 정리 5 = 90분.

## 03. 이미지 분류와 객체 인식, 같은 말일까?
객체 인식과 객체 검출의 영문을 함께 말한다. recognition을 detection의 고정된 동의어로 가르치지 않는다. 모든 이미지 분류가 반드시 단일 라벨인 것도 아니며 오늘의 범위를 명시한다.


핵심: “객체 인식 = 위치까지 찾기”로 단정하기보다, 분류·검출의 출력을 구체화한다.

## 04. 같은 장면도, 요구하는 답이 다르다.
분류 그림은 잘라 낸 컵을 사용한다. 여러 사물이 든 사진에 컵 하나가 유일한 정답이라고 오해하지 않게 한다. 검출 박스와 분할 마스크를 손으로 따라 짚는다.

질문: “컵이 두 개다”를 알려면 클래스 이름 하나로 충분할까?
핵심: 입력 사진이 같아도 정답의 형태가 다르면 다른 과제다.

## 05. 오늘 만들 답은 상자가 아니라 숫자다.
30초 개인 생각 후 두 단계로 설명하게 한다. 앞은 위치 찾기, 뒤는 숫자 분류라는 구분을 얻으면 충분하다. 여기서 아직 MNIST의 구성 설명은 하지 않는다.

질문: 번호판 사진에서 숫자 위치를 찾는 단계와 잘라 낸 숫자를 읽는 단계는 어떻게 다를까?
핵심: 과제를 먼저 정해야 라벨·출력·평가가 정해진다.

## 06. 사람은 다른 글씨를 어떻게 같은 7로 볼까?
그림은 손글씨 변형을 설명하는 도식이다. 실제 MNIST 표본은 뒤에서 보여 준다. 1분 개인 관찰, 1분 짝 설명을 배정한다.

질문: 세 모양을 같은 7로 본 단서와, 서로 달라도 무시한 차이를 적어 보자.
핵심: 같은 범주는 하나의 완벽한 사진과 동일하다는 뜻이 아니다.

## 07. 부분을 보고, 부분의 관계도 본다.
학생이 그림을 손으로 따라 그리게 한다. 뒤의 계층적 특징 조합으로 연결하되 특정 채널이 반드시 고리 뉴런이라고 말하지 않는다.

질문: 3의 열린 부분을 닫으면 어떤 숫자로 보일까? 한 획만 바뀌어도 의미가 달라질까?
핵심: 단서의 존재와 단서 사이의 관계를 함께 생각한다.

## 08. 경험과 맥락도 판단을 바꾼다.
가운데 같은 세로 획을 숫자/문자 문맥에 놓은 그림이다. MNIST 분류기에 문장 맥락을 입력한다고 설명하지 않는다. 생물학적 연구는 영감의 근거이지 일대일 복제 증명이 아니다.


핵심: 사람의 직관은 비유의 출발점이고, CNN의 동작은 실제 연산으로 확인한다.

## 09. 컴퓨터에게 그림은 밝기의 배열이다.
픽셀 격자에서 밝기와 경계의 차이를 설명한다. Flatten 자체가 정보를 삭제하는 것은 아니며 지역 구조를 어떻게 활용하는가의 차이라고 답한다.

질문: 숫자 하나만 보았을 때와 주변 3×3을 보았을 때 알 수 있는 것이 어떻게 다를까?
핵심: 픽셀 안에 “7”이라는 의미가 들어 있는 것은 아니다.

## 10. 사람의 표현을 계산 용어로 번역하기.
학생에게 사람의 비유 한 개를 실제 연산으로 다시 말하게 한다. 수용 영역을 눈동자의 시선 이동과 동일시하지 않는다.


핵심: 필터가 의식적으로 본다는 뜻은 아니다. 비유 뒤에 곱셈·합·배열·연결이 있다.

## 11. 필터: 작은 영역에 같은 질문을 던진다.
3과 0을 학생이 직접 계산한다. 딥러닝 Conv2d는 커널을 뒤집지 않는 교차상관을 사용하는 관례를 질문 때만 설명한다.

질문: 패치가 모두 1이면 반응은 얼마일까? 밝음 자체와 밝기 차이를 구분해 보자.
핵심: 합성곱 층은 같은 지역 계산을 위치마다 반복한다.

## 12. 특징 맵: 답 하나가 아니라 반응 지도.
PDF에서 슬라이더 조작을 요구하지 않는다. 웹은 COL 0의 반응3과 COL2의 반응0을 비교한다. 반전하면 출력 각 행은 [0,-3,-3]으로 방향 정보가 달라진다.


핵심: PDF는 고정된 첫 위치를 보여 주며, 웹에서는 필터를 직접 이동할 수 있다.

## 13. 채널: 서로 다른 질문의 답을 나란히.
한 필터가 일반적으로 모든 입력 채널을 함께 사용함을 짚는다. MNIST 모델은 입력1채널, 중간8·16채널, 마지막 10클래스로 이어질 것이라고 예고한다.


핵심: 채널 수는 중간 표현의 폭, 클래스 수는 최종 후보의 수다.

## 14. 공유: 같은 획을 다른 위치에서도 찾기.
계산량과 파라미터 수를 구분한다. 입력이미지가 커지면 계산량과 반응지도 크기는 늘 수 있다. 최종 분류 불변성이 자동 보장되는 것은 아니다.


핵심: 이미지에 유용한 반복 규칙을 구조에 넣는 대신, 위치별 자유도에는 제약을 준다.

## 15. 창의 크기와 이동 간격도 정한다.
padding1은 사방에 한 칸 추가하는 예다. 진짜 관찰값이 새로 생긴 것은 아니다. 실제 숫자를 계산하는 문제와 비유를 구분한다.


핵심: 3×3 필터·stride1에서 5×5 입력은 padding0이면 3×3, padding1이면 5×5 출력.

## 16. 반응을 바꾸고, 주변을 요약한다.
정답은 0,0,3 및 4. 음수에 의미가 없다는 주장이나 pooling이 완전한 이동 불변성을 만든다는 주장은 피한다.

질문: ReLU(−2,0,3)과 [1,4;2,3]의 max를 각각 말해 보자.
핵심: 비선형 변환은 조합의 표현력을, 공간 요약은 해상도와 정보 손실을 바꾼다.

## 17. 작은 획에서 더 넓은 관계로.
중간 비선형성과 채널이 있어 큰 필터 하나와 동일한 계산은 아니다. 마지막 MNIST 후보가0~9열개임을 다시 확인한다.


핵심: 작은 질문을 연결해 넓은 관계를 계산한다. 층마다 정해진 인간식 의미가 있는 것은 아니다.

## 18. 학습: 채점 결과로 기준을 조금씩 수정.
정답 확률0.8과0.1의 CE는 약0.223과2.303이다. 실제 인간의 반성·주의를 손실과 동일시하지 않는다. 60분 시점까지 용어 구간을 마무리한다.


핵심: 구조는 사람이 설계하고, 많은 필터 값은 라벨이 있는 예시로 조정한다.

## 19. 이제 한 데이터셋으로 모두 연결하자.
도입 1분. 실제 데이터와 설명용 도식이 바뀌는 경계를 명시한다. 공식 train 60,000장과 test 10,000장은 다음 페이지에서 설명한다.


핵심: 여기부터는 실제 MNIST 이미지와 실제로 실행한 작은 CNN 결과를 사용한다.

## 20. 같은 숫자도 이렇게 다르게 쓴다.
열마다 세 실제 표본을 보여 준다. 한 숫자를 골라 같은 라벨로 볼 근거를 말하게 한다. 공식 전체 데이터와 실험 부분집합을 섞지 않는다.


핵심: 한 숫자의 표본들을 보며 유지되는 구조와 달라지는 모양을 구분해 보자.

## 21. 28×28은 컴퓨터에게 784개의 밝기다.
확대한 6×6은 실제 test 표본의 좌표 [10:16,10:16]이다. 1채널과 10클래스를 혼동하지 않게 한다.


핵심: shape는 배열의 모양, label은 맞혀야 할 의미다.

## 22. 연습·점검·시험을 섞지 않는다.
seed 17로 층화 선택한다. train/val 인덱스 겹침을 검사한다. validation은 관찰용이며 최종 epoch 6은 test를 보기 전에 고정한다.


핵심: 뒤의 수치는 공식 test 10,000장 전체 성능이 아니라 고정한 1,000장 부분집합 결과다.

## 23. 숫자에 필터를 대면 획의 변화가 보인다.
좌우 필터의 각 행은 [-1,0,1], 상하 필터는 전치다. padding 1을 사용한다. 실제 계산이지만 학습된 모델의 해석 그림으로 소개하지 않는다.

질문: 가로획과 기울어진 획은 어느 지도에서 어떻게 보이는가?
핵심: 필터 반응 → 특징 맵이라는 용어를 실제 픽셀 변화에 연결한다.

## 24. 작은 CNN 안에서 크기가 어떻게 바뀔까?
Conv1 80개, Conv2 1,168개, Linear 7,850개로 합계 9,098개다. 중간 채널을 클래스 수로 설명하지 않는다. 펼치기는 배열 형태의 변경이다.


핵심: CNN 층은 특징을 만들고, 분류기는 그 표현을 숫자별 점수로 연결한다.

## 25. 실제로 학습시키면 곡선이 움직인다.
6epoch 최종 모델을 평가한다. 그림은 실제 실행 곡선이다. validation 곡선을 읽고 고정 test 평가와 구분한다.


핵심: 이 곡선은 실제 실행 결과다. 다른 초기값·환경·예산에서도 같은 수치가 보장되지는 않는다.

## 26. 한 장에서 10개 점수, 그중 하나의 예측.
실제 test 표본의 정답과 예측을 읽는다. 전체 부분집합 정확도와 한 표본의 softmax 값을 혼동하지 않는다. 사람과의 성능 비교 실험이 아니다.


핵심: 분류 출력은 후보별 점수와 라벨이다. 실제 위치 상자나 픽셀 마스크를 출력하지 않았다.

## 27. 활동: 사람의 단서로 오분류를 읽어 보자.
오류 그림은 실제 오분류 앞 6개다. 학생이 원래 라벨에 동의하지 않을 수도 있다. 애매한 표본 관찰과 모델 내부 원인 증명을 구분한다. 다음 주 배경 통제 실험으로 연결한다.


핵심: 맞힌 비율을 넘어서, 어떤 변화에서 실패하는지 질문하면 다음 실험이 된다.

## 28. 과제 → 사람 → 용어 → MNIST.
세 질문 모두 아니다. 분류·검출·분할의 출력 차이를 먼저 말하게 한다. 공식 자료와 원논문을 안내하고 개정 concept_practice.ipynb로 확장을 연결한다.


핵심: 출구 질문: 필터 반응은 숫자 확률인가? 출력 채널 수는 클래스 수인가? MNIST 분류기가 숫자 위치도 찾았나?
