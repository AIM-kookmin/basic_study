# CNN 2주차 개념 수업 · 리더 가이드

새 PDF와 웹페이지의 페이지 번호를 따릅니다. 기존 코드 중심 PPT의 페이지 번호와 다릅니다. 90분은 관찰·개념 설명·종이 활동·토론으로 구성합니다. 노트북 실행은 별도 선택 활동입니다.

## 운영 원칙
- 먼저 그림을 보고 예상한 뒤 설명을 읽습니다.
- 인간 시각과 CNN의 대응은 한계를 포함해 말합니다.
- 설명용 숫자·가상 사례를 실제 모델 측정값으로 소개하지 않습니다.
- 활동 해설 페이지는 개인·짝 계산 후 공개합니다.

## 01. 잘 맞혔다고, 잘 본 것일까?
고양이 실루엣에 낯선 무늬가 들어간 표지를 가리킨다. 참가자가 모양과 표면 무늬 중 무엇으로 답했는지 묻는다. 실제 모델 실행 결과가 아닌 사고 실험이다.


핵심: 정답뿐 아니라, 정답에 도달한 근거를 살펴보기.

## 02. 이번 주의 질문은 “왜 맞혔나?”
p1–3 5분, p4–7 15분, p8–10 15분, p11–15 15분, p16–22 15분, p23–24 15분, p25–28 10분. 선택 코딩은 별도 시간에 진행한다.


핵심: 도입 5 + 단서·데이터 15 + 변환 15 + 학습 설계 15 + 평가 15 + 활동 15 + 종합 10 = 90분.

## 03. 지난주 구조를 한 번에 복원하기.
형태를 이해했다는 표현의 증거를 묻는다. 높은 accuracy만으로 내부 표현에 대한 강한 결론을 낼 수 없다고 연결한다.

질문: “컵을 알아봤다”와 “컵 라벨을 맞혔다” 사이에 어떤 차이가 있을까?
핵심: 학습 목표가 “맞히기”일 때, 우리가 원한 방식으로 맞힐지는 따로 확인해야 한다.

## 04. 형태와 무늬가 서로 다른 말을 한다면.
이 연구의 모델과 훈련 조건에 한정해 설명한다. 인간도 질감과 맥락을 사용하며 언제나 형태만 사용한다는 이분법은 피한다.

질문: 윤곽은 그대로 두고 무늬만 바꾸면, 어떤 비교를 할 수 있을까?
핵심: 구조만으로 지각 방식이 완전히 결정되지 않는다. 데이터와 목표도 중요하다.

## 05. 쉬운 단서가 좋은 단서와 같지는 않다.
그림 속 결과는 실제 훈련 모델의 측정값이 아니라, 가능한 잘못된 규칙을 보여 주는 사고 실험이다. 배경을 항상 무의미한 정보라고 단정하지 않는다.


핵심: 학습 데이터에서 잘 작동하는 규칙이 우리가 원한 개념과 일치하는지 확인한다.

## 06. 좋은 데이터는 변화를 교차시킨다.
합성 배경 교체도 실물의 모든 변화와 같지 않다. 수집과 증강, 평가의 역할을 구분한다.

질문: 물체와 배경이 섞이지 않은 데이터에 증강만 추가하면 충분할까?
핵심: 데이터를 많이 모으는 일과 필요한 경우를 빠짐없이 모으는 일은 다르다.

## 07. 연습 문제와 마지막 시험을 나누는 이유.
물체 인스턴스 일반화가 목표라면 인스턴스 단위 분할을 제안한다. 모든 문제에 같은 그룹 분할이 정답인 것은 아니다.

질문: 한 컵을 연속 촬영한 100장을 무작위로 나누면 어떤 능력을 평가하게 될까?
핵심: 파일 이름이 다르다는 것보다, 평가에 필요한 독립성이 있는지가 중요하다.

## 08. 증강은 모델에게 보여 주는 변화다.
PDF는 원본·이동·가림·반전 네 상태를 함께 보여 준다. 웹에서는 버튼으로 큰 예시를 바꾼다. 실제 모델 예측을 제공하는 위젯이 아니다.

질문: 웹에서 변환을 바꾸고, 어떤 변환은 컵 분류에 괜찮지만 글자 인식에는 위험한지 말해 보자.
핵심: 증강은 상식의 자동 적용이 아니라, 데이터에 대한 가정이다.

## 09. 움직임을 따라가는 것과 무시하는 것.
경계 효과를 제외한 이상적인 조건과 실제 유한 이미지의 차이를 설명한다. feature map이 똑같아야 하는 것은 아니다.

질문: 특징 맵이 달라졌다는 이유만으로 분류 모델이 실패했다고 말할 수 있을까?
핵심: 입력 이동 → 특징 이동 / 입력 이동 → 같은 분류. 무엇을 비교하는지 먼저 정하자.

## 10. 작은 이동이 요약 결과를 바꿀 수도 있다.
그림은 1D 가는 선을 2칸 간격으로 샘플링하는 설명 예시다. 모든 pooling 구현의 출력이 동일한 방식으로 변한다는 주장은 아니다.


핵심: “조금 움직여도 괜찮을 것”이라는 기대는 실제 입력 변형으로 검증한다.

## 11. 채널을 늘리고 층을 깊게 하면.
폭과 깊이가 파라미터 수에 미치는 영향은 구조에 따라 다르다. 성능 비교에는 예산과 데이터 조건도 함께 적는다.

질문: 작은 데이터에서 성능이 낮을 때, 가장 먼저 모델을 크게 만드는 것이 합리적일까?
핵심: 모델 크기는 가능성을 늘린다. 좋은 일반화를 자동으로 보장하지는 않는다.

## 12. 더 깊다는 것의 두 얼굴.
참가자에게 세 개념을 한 문장씩 정의하게 한다. 이후 residual은 주로 최적화 경로, regularization은 일반화 설계의 관점으로 연결한다.

질문: train도 나쁜 모델과 train은 좋은데 validation만 나쁜 모델은 같은 처방이 필요할까?
핵심: 표현력, 최적화, 일반화는 함께 연결되지만 같은 단어가 아니다.

## 13. 처음부터 다시 쓰지 말고, 수정량을 더하자.
비유로 원고 수정량을 들 수 있지만 실제 네트워크가 의미 있는 초안을 읽고 고치는 것은 아니다. x와 F(x)는 숫자 텐서다.


핵심: 입력을 전달하는 경로와 입력을 수정하는 경로를 함께 둔다.

## 14. 값의 크기도 학습 환경의 일부다.
학습 모드는 batch 통계, 일반적인 평가 모드는 running 통계를 사용한다. 논문이 제시한 초기 설명을 현재의 유일한 원인으로 단정하지 않고 동작과 용도 중심으로 말한다.


핵심: 입력 전처리와 네트워크 내부의 정규화를 구분해 이름 붙인다.

## 15. 한 단서에만 기대지 않게 유도하기.
Dropout을 “다른 뇌 영역이 대신 일한다”는 식으로 설명하지 않는다. 생물학적 대응이 아닌 확률적 학습 기법이다.


핵심: 규제는 학습을 돕는 선택지이며, 성능을 올리는 만능 장식이 아니다.

## 16. 학습 곡선은 진단을 시작하는 그림이다.
학습 곡선 이미지는 실제 실행 결과가 아니라고 페이지에 표시한다. 진단 가설과 확정 결론을 구분한다.


핵심: 관찰 → 가능한 원인 → 한 변수 변경 → 재측정. 오른쪽 곡선은 설명용 합성 값이다.
